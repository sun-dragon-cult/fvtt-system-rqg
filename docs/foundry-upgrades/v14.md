## Findings

### Removed / hard break

#### F1 — bare `randomID()` global removed

- **RQG:** `src/sockets/rqg-socket.ts:19` (`socketRequest()`, request/response socket path).
- **Foundry:** v13 `client/client.mjs:181` shims every `foundry.utils.*` function onto
  `globalThis` with `{since: 12, until: 14, once: true}`. v14 removed that loop; `randomID`
  is not in v14's `Object.assign(globalThis, …)` block (`client/client.mjs:52`). Bare call →
  `ReferenceError: randomID is not defined`.
- **Masked by types:** `fvtt-types` still declares `randomID` as an ambient global
  (`client.d.mts:2520`), so `tsc` passes. Not catchable by typecheck.
- **Fix:** `foundry.utils.randomID()` — applied 2026-09-10.
- **Deadline:** already removed in 14.
- **State:** `fixed`
- **Notes:** only bare `foundry.utils.*` global in RQG src. `fromUuid` / `fromUuidSync`
  (also used, un-namespaced) are still real v14 globals — not affected.
